======================================================================
TASK 2 – DATA CLEANING
======================================================================

Requirements:
- Handle missing values.
- Remove rows with null CustomerID.
- Remove duplicates.
- Fix invalid Quantity values.
- Fix invalid UnitPrice values.

IMPORTANT FUNCTIONS / COMMANDS:

1. Check missing values
   df.isnull().sum()

2. Remove rows where CustomerID is missing
   df = df.dropna(subset=["CustomerID"])

3. Check duplicate rows
   df.duplicated().sum()

4. Remove duplicate rows
   df = df.drop_duplicates()

5. Check negative Quantity
   df[df["Quantity"] < 0]

6. Keep only valid positive Quantity
   df = df[df["Quantity"] > 0]

7. Check invalid / zero UnitPrice
   df[df["UnitPrice"] <= 0]

8. Keep only valid UnitPrice
   df = df[df["UnitPrice"] > 0]

9. Reset index after cleaning
   df = df.reset_index(drop=True)

10. Check missing values again
    df.isnull().sum()

11. Check final dataset size
    df.shape


======================================================================
TASK 3 – FEATURE ENGINEERING
======================================================================

Requirements:
- Create TotalPrice.
- Extract Year, Month, Day, and Hour.
- Create Customer Segment.
- Create Order Size.
- Create Day Type.

--------------------------------------------------
A. CREATE TOTALPRICE
--------------------------------------------------

Formula:
TotalPrice = Quantity × UnitPrice

Code:
df["TotalPrice"] = df["Quantity"] * df["UnitPrice"]

--------------------------------------------------
B. EXTRACT DATE / TIME FEATURES
--------------------------------------------------

Make sure InvoiceDate is datetime first:

df["InvoiceDate"] = pd.to_datetime(df["InvoiceDate"])

Year:
df["Year"] = df["InvoiceDate"].dt.year

Month:
df["Month"] = df["InvoiceDate"].dt.month

Day:
df["Day"] = df["InvoiceDate"].dt.day

Hour:
df["Hour"] = df["InvoiceDate"].dt.hour

Optional month name:
df["MonthName"] = df["InvoiceDate"].dt.month_name()

Optional day name:
df["DayName"] = df["InvoiceDate"].dt.day_name()

--------------------------------------------------
C. CUSTOMER SEGMENT
--------------------------------------------------

Customer Segment can be created based on customer spending.

First calculate customer-level spending:

customer_spending = df.groupby("CustomerID")["TotalPrice"].sum()

Example using pd.cut:

df["CustomerSegment"] = pd.cut(df["TotalPrice"],bins=[0, 50, 500, float("inf")], labels=["Low", "Medium", "High"])

--------------------------------------------------
D. ORDER SIZE
--------------------------------------------------

Example based on Quantity:

df["OrderSize"] = pd.cut(
    df["Quantity"],
    bins=[0, 5, 20, float("inf")],
    labels=["Small", "Medium", "Large"])

--------------------------------------------------
E. DAY TYPE
--------------------------------------------------

Create weekday/weekend category:

df["DayType"] = df["InvoiceDate"].dt.dayofweek.apply(
    lambda x: "Weekend" if x >= 5 else "Weekday")

Alternative:

df["DayType"] = np.where(
    df["InvoiceDate"].dt.dayofweek >= 5,
    "Weekend",
    "Weekday")

IMPORTANT FUNCTIONS:
- .dt.year
- .dt.month
- .dt.day
- .dt.hour
- .dt.day_name()
- .dt.month_name()
- pd.cut()
- np.where()
- lambda
